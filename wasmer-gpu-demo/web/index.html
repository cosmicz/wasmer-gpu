What this proves

The browser controls a local process. Wasmer runs core WebAssembly modules and one WASIX command guest, each carrying its own WGSL. The same host bridge connects them to wgpu and the native adapter; the WASIX guest receives it through the runtime's instantiation hook.

Only owned demo shaders run here. WASIX coverage is one command guest without threads, files or network. This is not a complete WebGPU API, GPU isolation, or distributed training.
